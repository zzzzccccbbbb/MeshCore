# LR20xx shields

This README describes the LR20xx shields characteristics.

# List

The list of compatible Semtech LR2021 shields is:

| Shield          | Frequency matching | Characteristics |
| --------------- | -------- | ------------------------------------------------------------------------------ |
| LR2021MB1LDZCS | 868/915 MHz | LR2021 arduino shield @868/915MHz for EU/US LoRa subGHz and @2.4GHz Frequency Bands – Switchless version for each RF path |
| LR2021MB1LGZCS | 490 MHz | LR2021 arduino shield @490MHz for China LoRa subGHz and @2.4GHz Frequency Bands – Switchless version for each RF path |
| SEEEDUINO XIAO EXT 868 | 868 MHz | LR2021 seeeduino xiao-based arduino shield @868MHz connected with arduino-uno-like header |

## Legenda

| Symbol | Meaning |
| ------ | ------- |
| IC | LR2021| 
| MB1 | mbed shield version 1 | 
| L | Reserved for future use | 
| D | 868/915 MHz common frequency bands for LoRa RF path| 
| G | 490 MHz common frequency bands for LoRa RF path| 
| Z | 2.4 GHz frequency band for high frequency 2.4 GHz RF path| 
| C | Switchless RF path implementation (for each RF path)| 
| A | RF Switch RF path implementation (for each RF path)| 
| S | SMA Antenna connector|
